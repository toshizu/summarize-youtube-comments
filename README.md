# YouTubeコメント要約ツール

YouTube動画のURLを入力してボタンをクリックすると、AIが視聴者の反応を要約してくれるツールです。

制作物(ポートフォリオ)として作成いたしました。

[summarize-youtube-app](https://summarize-youtube-app-667615213744.asia-northeast1.run.app/)

## 強み

この制作物のアピールポイントは以下の通りです。

* API活用による、**様々なWebサービスを繋げた独自システムが構築可能**
* FastAPI,Streamlit,Dockerにより、**直感的で使いやすいUIの実現**
* Google Cloud(Cloud Run)を採用することで、**URLで簡単にシステムへアクセス**

内部的には、YouTube動画に寄せられたコメント(返信コメントは除く)といいね数を一括で取得し、そのデータをAIに渡してサマリーを出力させています。

プログラミングとAIによって、数千件ものコメントが寄せられていたとしても、ボタン1つで

* コメントデータの一括取得
* AIによるデータの要約

が実現し、**膨大な情報から「エッセンス」を抽出**してお渡しすることができます。
